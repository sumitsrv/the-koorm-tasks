# data/

Nothing here is hand-edited in place — every file is either authored in
`src/gold_*.py` or generated by a pipeline script, and can be reproduced by
re-running that script. See the root [README](../README.md#pipeline) for the
full pipeline walkthrough; this file is the map of what lives where.

```
data/
├── train.jsonl          combined, shuffled training set — what train.py reads
├── gold/
│   └── plan_gold.jsonl  hand-authored examples — `python src/gold.py`
└── distilled/
    ├── descriptions.json   expanded task descriptions (cache; append-only)
    ├── plan_train.jsonl    v1 distilled data, repaired — `python src/repair.py --apply`
    ├── plan_ollama.jsonl   this pipeline, local teacher  — `python src/generate.py --teacher ollama`
    ├── plan_claude.jsonl   this pipeline, hosted teacher — `python src/generate.py --teacher claude`
    ├── schedule_train.jsonl    schedule-adjustment examples (teacher-generated)
    ├── schedule_ollama.jsonl
    └── schedule_claude.jsonl
```

| File / dir | Produced by | Regenerate with |
|---|---|---|
| `train.jsonl` | `generate.py::combine()` — merges every source below | `python src/generate.py --combine-only` |
| `gold/plan_gold.jsonl` | hand-authored `src/gold_*.py` modules | `python src/gold.py` |
| `distilled/descriptions.json` | seed expansion (`scenarios.py` + a teacher) | `python src/generate.py --teacher <ollama\|claude>` |
| `distilled/plan_<teacher>.jsonl` | distillation from a teacher model | same as above |
| `distilled/plan_train.jsonl` | v1 corpus salvage | `python src/repair.py --apply` |
| `distilled/schedule_*.jsonl` | schedule-adjustment distillation | `python src/generate.py --teacher <name>` |

`distilled/*.repaired.jsonl` and `distilled/*.v1.bak` are `repair.py`
intermediates (dry-run output and pre-apply backup) — gitignored, not part of
the corpus itself.

Tracked in git by default because it's a few MB and takes hours to
regenerate — see `.gitignore` if you'd rather keep generated data local only.
